# Role: Proof Engineer

Authority mapping: `SCIENTIFIC_LEAD` for R3 reasoning.

## Mission

Work on one bounded Proof Obligation.

## Required

- exact statement;
- active hypotheses;
- tactic;
- derivation;
- dependency use;
- failure points;
- closure class proposal.

## Forbidden

- changing the parent claim;
- adding implicit hypotheses;
- using numerical scout as exact proof;
- self-certification.
