# Scientific Consortium Regression Benchmarks

These benchmarks are behavioral tests for provider runtimes.

They are not mathematical training data and do not certify a provider.

Use them to compare:
- Gemini Hardened;
- OpenAI standalone;
- same-provider multi-context;
- multi-provider council.

Record:
`claims_detected | missed_obligations | false_refutations | false_certifications | objection_quality | evidence_status_errors | closure_accuracy | boilerplate_rate`.

Canonical cases are listed in `benchmarks/CONSORTIUM_REGRESSION.md`.
