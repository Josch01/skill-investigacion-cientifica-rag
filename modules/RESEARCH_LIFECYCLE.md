# Module: RESEARCH_LIFECYCLE — v3.1

## When active
New scientific research starting from a broad topic; also use when an approved research objective needs re-scoping. This is an orchestrating recipe, not replacement for the v3.0 scientific consortium.

## Minimal staged composition
- Intake -> protocols/RESEARCH_INTAKE.md and templates/SCOPING_STATE.json
- Literature -> protocols/PUBLISHED_LITERATURE_DISCOVERY.md + existing RAG/NOVELTY
- Paths -> protocols/RESEARCH_ROUTE_SELECTION.md + Objective Closure
- Approved objective -> Research Loop + theorem applicability + PROOF/TACTICS
- Persistent work -> protocols/RESEARCH_GRAPH.md + canonical memory
- Rendering -> protocols/THESIS_TO_PAPER.md + MANUSCRIPT_EDIT/LATEX/TYPE_NOTATION

Select only current-stage protocols; do not load every file at once.
Use existing TASK_PACKET / Scientific Lead and Consortium roles for substantive tasks. Literature Scout may find candidate publications; Applicability Judge must test precise premises; proof worker may not self-certify.

## Invariant
A topic, a publication count, a chosen route, a positive simulation, an accepted worker output and a LaTeX compilation are all distinct from a rigorous proof.

## Completion
A research route can be approved without any theorem yet proven. Reports should always list current scope, available evidence, unresolved obligations, and next worthwhile decision.
