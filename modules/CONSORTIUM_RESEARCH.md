# Module: CONSORTIUM_RESEARCH

## Activate when

Use for substantive open scientific objectives that require several of:

- literature/theory scan;
- theorem applicability checks;
- multiple proof obligations;
- adaptive analytic vs computational strategy;
- falsification/counterexample search;
- cross-domain expertise;
- dispute resolution;
- independent second review.

This module is additive.
It does not replace v2.12 Research Loop, Proof, Numerics, Certification, Audit, handoff, or memory protocols.
